# Sales

The owner's sales function, and the one domain in [[My Shared Brain]] with real content behind it.

## Two homes
- `context/sales/` - the routed domain folder, intended for sales methodologies, objection scripts, lead generation, closing techniques and CRM workflows. It is empty. See [[Context Routing Index and Domain Folders]].
- `workspaces/Sales/` - the working copy: `Context/` (eight notes), `Workflows/` (the lead-extraction workflow and its script) and `Leads/` (the May 2026 export). See [[Sales Context File Set]] and [[Extract IMCRM Health Leads Workflow]].

## What the domain covers
- **CRM:** [[IMCRM]] - filtered Health List, lead detail pages, statuses and stages. See [[IMCRM Health Lead Detail Extraction Guide]].
- **Messaging:** [[WhatsApp Business]] follow-up, read and draft only.
- **Lead handling:** priority order, hot signals, escalation. See [[Lead prioritization]].
- **Replies:** the house style. See [[Client message style]].
- **Targets and focus:** see [[Business Goals]].
- **Limits:** see [[Automation guardrails]].

## Caveats
- The duplication between `context/sales/` and `workspaces/Sales/Context/` is unresolved; an agent following the routing table lands on the empty folder.
- The Sales workspace is described in the shared manual as a workspace, but the manual's own workspace table lists only the Media Extraction Lab. See [[Shared Agent System Manual]].
