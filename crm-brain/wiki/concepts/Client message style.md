# Client message style

The house style for messages sent to clients, set in `message-style.md` in the Sales workspace context. See [[Sales Context File Set]].

## The style
- Concise, direct, professional, helpful without fluff.
- Move the client toward the next step.
- Keep replies easy to read; simple language; no long paragraphs unless an explanation is genuinely needed.

## The next steps a reply should reach for
Confirm documents, confirm the quote, schedule a call, send a payment link, or ask one clear closing question. One of these, not a menu.

## What to avoid
Overexplaining, vague follow-ups, passive wording, and an overly formal corporate tone.

## The supporting rules
- Drafting is allowed; sending is not, unless explicitly instructed. See [[Automation guardrails]] and [[WhatsApp Business]].
- Reading chat previews to summarise is allowed; opening a conversation is only needed when exact context is required. See [[Sales Context File Set]].
- A third-party sales post saved in the vault argues for the same instinct from a different angle: "send me more info" is a brush-off, so reply with a question rather than another document. See [[Info request is not a buying signal]].

## Caveats
- The style sheet is about client replies; it says nothing about internal notes, email subject lines or document tone.
- It says "professional" and "avoid corporate tone" at the same time, which is a tension the owner resolves case by case.
