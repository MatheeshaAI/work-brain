| IMCRM Gender Field | Salutation |
|--------------------|------------|
| Male / Male-Married / Male-Unmarried | Mr. |
| Female-Married | Mrs. |
| Female-Unmarried | Miss |
| Female (no marital status) | Ms. |
| Age < 18 (any gender) | First name only (no title) |
