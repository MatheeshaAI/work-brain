# Memory — Health Insurance CRM

## Task Management — Single Source of Truth
- **All tasks/todos** are managed in `Workspace/tasks.md` ONLY.
- When user says "add to tasks" or "add to todos" → add to `Workspace/tasks.md`.
- Do NOT use session-only todo lists as the primary tracker — always mirror to `Workspace/tasks.md`.
- PIPELINE.md checklist section is for daily operational reminders, but `Workspace/tasks.md` is the master task file.
- Task types: Follow-up, Documents, Plans, Quotation, Enrollment, Admin, Other.
- Statuses: To-do, In Progress, Completed This Week, Overdue.

## Lead Management
- Leads tracked in `Workspace/Leads/[REF_ID]-[Name].md`
- Pipeline dashboard: `Workspace/PIPELINE.md`
- Renewals: `Workspace/Renewals/` + `Workspace/RENEWALS.md`
- Documents: `Workspace/Documents/[REF_ID]-[Name]/`

## Key Workflows
- New lead → Create lead file, add to PIPELINE.md, add task to tasks.md, send WhatsApp
- Quotation → Add Quotation task to tasks.md, update lead status
- Policy booking → Follow SOP, update all files, move task to Completed
- Renewals → Create renewal file, add to RENEWALS.md, add task to tasks.md
