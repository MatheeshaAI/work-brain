# WhatsApp Business

## Main use
Use WhatsApp Business in the work browser profile for follow-up and lead communication support.

## What can be done
- List unread chats
- Summarize unread chat previews
- Open a controllable WhatsApp Web tab
- Draft next actions based on chat content

## Rules
- Do not send messages unless explicitly instructed
- Reading from chat previews is fine for summaries
- If exact message context is needed, open the chat only when necessary
- Keep work chats separate from personal chats

## Known patterns
- Unread chats can be filtered from the chat list
- A preview summary can often be made without opening every conversation
- Controlled tabs are preferred over relying on existing unmanaged tabs
