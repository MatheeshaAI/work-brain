# Browser Profile

## Main work profile
Use the browser profile that is logged into:
- IMCRM
- WhatsApp Business
- Gmail

## Rules
- Prefer opening a fresh controlled tab for automation tasks
- Existing tabs may be visible, but controlled tabs are safer for interaction
- For IMCRM work, open a controllable tab before extracting or navigating
- For WhatsApp work, open a controllable WhatsApp Web tab before reading chats or drafting actions
- Avoid mixing personal and work profiles during sales tasks

## Notes
- The browser harness can see other tabs in the same profile
- It can safely control tabs it opens itself
- If the wrong profile is open, switch to the correct work profile before starting sales tasks
