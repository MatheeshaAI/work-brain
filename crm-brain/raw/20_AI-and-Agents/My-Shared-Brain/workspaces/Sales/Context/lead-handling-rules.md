# Lead Handling Rules

## Priority order
1. New Lead
2. Quoted
3. Application Pending
4. Qualified
5. Followed Up but stale
6. Lost

## Hot lead signals
- Asking for payment link
- Asking for final confirmation
- Asking for hospital/network confirmation
- Asking for urgent update
- Large premium case
- Ready-to-buy language

## Suggested handling
- **New Lead** → fast first contact
- **Quoted** → follow up with decision push
- **Application Pending** → remove blockers quickly
- **Qualified** → move toward quote / docs / payment
- **Followed Up** → check staleness and re-engage smartly
- **Lost** → keep record, review reason, avoid wasting time unless recoverable

## Escalation logic
- Big premium + clear intent = high priority
- Any client waiting on your confirmation = high priority
- Old stale low-intent leads = lower priority unless strategic
