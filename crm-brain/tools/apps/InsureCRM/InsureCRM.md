# InsureCRM

**InsureCRM** is an insurance agency CRM dashboard designed to help agents track renewals, premiums, commissions, leads, tasks, and client relationships — all in one place.

It was built as a static HTML/CSS/JS mockup/prototype for an insurance agency based in the UAE.

### What it does

- Tracks **monthly renewals** and the premium generated from them
- Monitors **premiums collected** and **commissions earned** against office targets (AED 200,000 / AED 20,000)
- Visualizes the **lead pipeline** across 5 stages — New → Contacted → Qualified → Proposal → Closed-Won
- Manages **pending tasks** with priorities and due dates
- Stores **client contacts** with full personal details, email, phone, and policy information
- Shows **monthly history** with 6-month trend data for premiums and commissions
- Supports **light and dark mode** with persistent theme preference

### Status

**Prototype / Design Mockup** — visually complete, functionally limited. All data is hardcoded. Ready for backend integration.
