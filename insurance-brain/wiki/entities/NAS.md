# NAS

A TPA with a specialist agent ("NAS Standard Specialist") in [[TPA Network Lookup Agents]]. Source: [[YOUR MULTI-AGENT TEAM STRUCTURE]].

**Specialty:** budget plans, SME groups, labor insurance.

**6 networks** (see [[Network tiers]]):
- Comprehensive Network: premium tier
- General Network: mid tier
- Restricted Network: economy tier
- Super-Restricted Network: budget tier
- Workers Network: labor and basic coverage
- Value Network: budget tier

**In the examples:** it is the cheapest option for several scenarios (Comprehensive AED 1,800 a year; AED 7,200 for the example family, "best value"; General AED 1,400, cheapest for Burjeel Abu Dhabi). All prices are illustrative.

**Inconsistency:** the scenario 2 answer lists NAS Comprehensive as the "budget option" although the agent list calls it the premium tier.

Compare: [[Mednet]], [[Dubai Care]], [[Nextcare]].

See also (added): [[Network plan code list (NAS_CN)]] for the plan codes of this network.

## Where it sits in the work_os reference lists (2026-10-22 ingest)
The work_os TPA list gives NAS **5 networks** - CN, GN, RN, SRN, WN - and describes it as a strong network for **Abu Dhabi**. The multi-agent design gives **6**, spelling them out as Comprehensive, General, Restricted, Super-Restricted, Workers and Value. Source: [[TPAs and Networks Reference (Work OS)]], [[YOUR MULTI-AGENT TEAM STRUCTURE]].

CN/GN/RN/SRN/WN and Comprehensive/General/Restricted/Super-Restricted/Workers/Value are two vocabularies for the same structure; the difference is **Value**, which only the multi-agent list has - the 5-code plan list drops it, along with dental and optical. See [[TPA and network reference]], [[Network plan code list (NAS_CN)]].

The abbreviation is also used as a **plan code** in the vault's code lists - `NAS_CN` is the Comprehensive Network code, which is why the plan-code page and the network page both mention it. See [[Network plan code list (NAS_CN)]].
