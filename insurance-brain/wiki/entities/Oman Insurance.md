# Oman Insurance

**Stub.** One May 2026 renewal case in the workspace is with **Oman Insurance**, filed under the code **`OI2`** with a policy number in the Oman form `P/01/<year>/<serial>`. Source: [[Client dossiers]], [[Renewals board]].

**Correct an earlier reading.** The wiki previously took `OI2` to be [[Orient Insurance]], whose page carried that code. The renewal file itself names the insurer: *"Provider: Oman Insurance (OI2)"* with an Oman-style policy number. [[Orient Insurance]] has been corrected; the two are unrelated, and Orient appears in the commission exports under its own name with no renewals.

Oman Insurance has **no plan file in the plan library** and no underwriting notes in the knowledge base - so the desk is renewing a policy it does not otherwise quote. That is the one thing worth knowing about it. See [[Renewal pipeline]] and [[Insurance plan sheets]].

**One more clue.** The CRM's entry-level sample names **Sukoon** as the network Oman Insurance writes on, so the insurer is reachable through that network even though the workspace library holds no file for it. See [[Network tiers]].
