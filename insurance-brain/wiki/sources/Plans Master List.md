# Plans Master List

A 424-line Markdown table of every plan (418 rows), columns row number, provider, plan name, plan type, network, co-pay and price. It is the same data as [[Plans Table 418 Plans]] (the sales-report export) with padded columns, ordered from "Dubai Care Exclusive N2" at row 1 down to BUPA Ultimate at row 418. The 22 per-insurer files are cuts of this table; the insurer-level summaries are in [[Plan library]].

Notes
- Row order puts cheap entry plans first after a single expensive plan (row 1), so the list is not a clean price sort; the early rows are Fidelity Plan G, QIC BLUE01, Takaful Emarat E Care Blue 1 and similar.
- There are two copies of the same table in the workspace, so edits must be mirrored; no source says which one is canonical.
- File size is about 131 KB, the largest in the Plans folder.
