## What it says about the folder
- **Four notes are indexed, but only three files exist.** `Plans-WXD99WYY-Mariamma-Jose.md` is **not in the folder** - the folder holds `Dubai-Insurance.md`, `Takaful-Emarat.md`, `General-Underwriting.md` and this index, nothing else. The index therefore points at a file that was deleted, moved or never created.
- **The missing note is the one that would have been the plan catalogue.** Its subject - 418 plans with price, network, co-pay and VAT - is exactly what `Plans/Plans.md` now holds. The likely reading is that the client-scoped plan note was replaced by the shared plan library, and the index was never updated. That is a **design intent, not a recorded fact** - the note's own text is gone.
- **Every note is dated "Noted: April 2026"**, so the knowledge base is roughly six weeks older than the plan sheets (1 May 2026).

## Contradictions
- The index says "all 418 available plans", which matches the plan library exactly - see [[Insurance plan sheets]] and [[Plan catalogue raw exports]].
- The index lists the file that is missing, so the folder's own documentation is out of date with the folder.
