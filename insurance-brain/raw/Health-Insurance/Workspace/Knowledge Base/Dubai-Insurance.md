# Dubai Insurance — Underwriting Notes

## Ramento Plans — Child-Alone Policies

**Applicable age range:** 6–12 years

Child-alone policies are only accepted if **one** of the following conditions is met:

- Sponsor parent is insured with **any insurer** (policy copy to be uploaded)
- Both parents are insured with **any insurer** (policy copy to be uploaded)
- One parent is insured with **Dubai Insurance on the same or higher plan** (policy copy to be uploaded)

*Noted: April 2026*
